# husainzafar.github.io

This repository used to host a Jekyll blog. All content has moved to
**[husainzafar.com](https://husainzafar.com/)**.

The repo is kept only so GitHub Pages can serve a redirect:

- `index.html` — redirects the root to husainzafar.com.
- `404.html` — forwards any other path to husainzafar.com (which handles its
  own 404s).
- `.nojekyll` — serve these static files directly, skip the Jekyll build.

Deleting this repo would make `husainzafar.github.io` stop resolving, so the
redirect would break. Keep it.
